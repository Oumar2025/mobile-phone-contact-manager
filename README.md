# Mobile Phone Contact Manager

A simple Java Swing GUI application for managing phone contacts.

## Features

* Add Contact
* Edit Contact
* Delete Contact
* Prevent Duplicate Phone Numbers
* Input Validation
* Contact List Display using JTable

## Technologies Used

* Java
* Java Swing
* JTable
* DefaultTableModel
* VS Code

## Project Structure

```text
PhoneContactGUI
│
├── src
│   └── App.java
│
├── bin
│   └── App.class
│
└── README.md
```

## How to Run

Compile the program:

```bash
javac -d bin src/App.java
```

Run the program:

```bash
java -cp bin App
```

## Learning Objectives

This project demonstrates:

* Java GUI Development
* Event Handling
* CRUD Operations
* Input Validation
* Table Management using JTable
